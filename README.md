# My Shawarma Brampton website

Static HTML, CSS and JavaScript website for the My Shawarma location at 4525 Ebenezer Rd #8, Brampton, ON.

## Deploy
Vercel is connected to this GitHub repository. The homepage is `index.html` in the repository root. Every push to `main` triggers a deployment.

Food images are illustrative external Unsplash images. Confirm menu, prices, and delivery links with the restaurant before public promotion.
